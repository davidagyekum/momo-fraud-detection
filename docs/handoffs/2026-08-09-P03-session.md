## Security/privacy

- Server stores only Argon2id password hashes and HMAC hashes of refresh/reset tokens.
- Browser refresh uses an HTTP-only cookie plus a CSRF value bound to that cookie with the server
  CSRF secret; mobile refresh storage is restricted to Expo SecureStore.
- Refresh rotation is one transaction. Reuse revokes the remaining token family.
- Access checks validate expiry, user state, token version and the current role set.
- Ownership policy returns no object for absent or cross-user transaction identifiers.
- Login/reset/role/deactivation/revocation events are appended to immutable audit storage.
