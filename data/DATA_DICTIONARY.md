# Data Dictionary

The portable JSON schemas under `data/schemas` are authoritative for field types. This dictionary explains their research meaning and missingness rules.

## Structured transaction

| Field | Meaning | Missingness/privacy rule |
|---|---|---|
| `step` | Source-relative simulation/event step | Never inferred from OCR |
| `transaction_type` | Registered source transaction category | Preserve source mapping/version |
| `amount` | Source transaction amount | Required; never copied from a screenshot into transaction-only training data |
| `initiator_id`, `recipient_id` | Source pseudonyms | Must not be names, phones or production user IDs |
| balance fields | Source-provided before/after balances | Nullable; missing values remain null and never become zero |
| `label_is_fraud` | Source label | Must retain source provenance; never generated by application rules |
| `dataset_source`, `source_row_id` | Registered origin/version row key | Required for grouping, withdrawal and reproducibility |

## Screenshot and OCR

| Field | Meaning | Missingness/privacy rule |
|---|---|---|
| `image_id` | Non-identifying fixture/research identifier | No name/phone/reference in filenames or IDs |
| `source_group_id` | Original/derivative grouping key | Split before preprocessing/augmentation |
| `participant_id_hash` | Pseudonymous withdrawal key | Required for controlled-real records; null for synthetic/external sources |
| `image_class` | Visible manipulation label | `unaltered` or `tampered`; never genuine/fake |
| tamper/benign fields | Declared edit or non-semantic transform | `none` is explicit, not missing |
| OCR fields and boxes | Field-level transcription truth | Direct values remain private unless fictitious or release-approved |
| `consent_scope` | Internal/release/synthetic permission scope | Required; public release needs `release_approved` |
| `permission_reference` | Opaque approval/licence record key | Never embed a completed consent form or credential |

## Split and run records

- Split groups must be non-empty, unique and disjoint. `frozen: true` is required before a reportable run.
- Run records store exact code, environment, dataset and split hashes. `repo_dirty` must be false.
- A run manifest is provenance, not evidence that data rights, accuracy or model acceptance passed.
