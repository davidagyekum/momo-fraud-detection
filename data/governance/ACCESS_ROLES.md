# Data Access Roles

| Role | Raw participant data | De-identified working data | Consent/withdrawal linkage | Release approval |
|---|---:|---:|---:|---:|
| Data steward | As approved | Yes | Yes | Recommends/records approval |
| Researcher | Only when separately approved | Yes | No direct linkage | No |
| Annotator | No | Assigned minimum subset | No | No |
| Model operator | No by default | Approved frozen manifest only | No | No |
| Reviewer/auditor | No by default | Safe manifests/aggregates | Status evidence only | Reviews |
| Public user | No | Release-approved artifacts only | No | No |

Every grant must be purpose-limited, time/review bounded and revocable. Administrator application roles do not automatically grant research-dataset access.
