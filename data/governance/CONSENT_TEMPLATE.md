# Consent Template — Not a Completed Record

> Store completed consent records outside Git in restricted governance storage.

Participant confirms that they:

- received and understood the approved participant information;
- had questions answered and participate voluntarily;
- understand what screenshots/metadata are collected and the recorded research purpose;
- understand restricted storage, authorised roles and the withdrawal process;
- understand that model outputs are research evidence, not provider verification.

Required independent choices:

- [ ] **Internal research consent:** use de-identified/pseudonymised data within the approved project.
- [ ] **Controlled derivative consent:** create declared research edits/derivatives while preserving withdrawal linkage.
- [ ] **Public release consent (optional and separate):** release only the specifically described de-identified items. Leaving this unchecked means `internal_only`.
- [ ] **Future related research consent (optional and separate):** only within the described scope; otherwise prohibited.

Record participant signature/approved equivalent, researcher, date, document version and opaque permission reference privately. Repository manifests contain only the opaque reference and `internal_only` or `release_approved` scope.
